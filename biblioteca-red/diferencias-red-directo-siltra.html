Diferencias entre RED Directo y Sistema de Liquidación Directa

Comparación de canales, límites de trabajadores, cálculo, remesas, software y documentos entre RED Directo, SLD y el método histórico RED Internet.

Comparación de canales, límites de trabajadores, cálculo, remesas, software y documentos entre RED Directo, SLD y el método histórico RED Internet.

RED Directo

Opera desde la oficina virtual sin programa de nóminas y está orientado a pequeñas empresas, con el límite visible de 15 trabajadores o hasta 25 bajo la condición de solicitud indicada.

SLD

Permite oficina virtual para afiliación/IT y remesas para cotización. Requiere SILTRA y ficheros XML generados por un programa de nóminas; la TGSS calcula a nivel de trabajador y contrasta la información antes de liquidar.

RED Internet

La fuente lo presenta como modalidad anterior a 2015, basada en Winsuite32 y actualmente descontinuada.

Imágenes del proceso

Advertencias y validaciones
  • El límite de RED Directo es el que publica la fuente; superar el umbral provoca bloqueo y migración a SLD.
  • En SLD la cotización no se presenta manualmente desde la oficina virtual, sino por remesas SILTRA.
