CASIA del Sistema RED

Servicio de tickets para consultas, errores/incidencias y trámites, con anexos, filtros, estados, histórico, resolución y modificación de casos abiertos.

Servicio de tickets para consultas, errores/incidencias y trámites, con anexos, filtros, estados, histórico, resolución y modificación de casos abiertos.

Acceso y finalidad

CASIA está dentro de la oficina virtual RED y solo disponible para autorizados RED. Permite abrir casos, adjuntar documentación, consultar respuestas y seguir estados.

Tipos de caso

Consulta, error/incidencia y trámite. La solicitud de aplazamiento no se realiza por CASIA según la nota visible de la página.

Gestión y estados

Los casos pueden estar abiertos/presentados, asignados, con información solicitada, escalados o transferidos; y cerrados/anulados, resueltos o de oficio. Los casos cerrados ya no se pueden modificar ni anular.

Procedimiento paso a paso

Paso 1Abrir Nuevo Caso

Elegir la opción en la pantalla principal.

Paso 2Clasificar

Seleccionar tipo, materia, categoría y subcategoría.

Paso 3Describir

Informar periodo, título, descripción y datos complementarios.

Paso 4Anexar

Elegir tipo y título de documento y cargar archivos.

Paso 5Finalizar alta

Obtener justificante, fecha/hora y número de caso; se envía aviso por correo.

Paso 6Gestionar el caso

Consultar, añadir información o ver la respuesta desde Gestión de Casos, no abriendo otro caso.

Paso 7Consultar histórico

Ver estados, observaciones y resolución; realizar encuesta cuando cierre el tramitador.

Imágenes del proceso

Advertencias y validaciones
  • Solo los autorizados RED pueden usar CASIA.
  • Para añadir documentación a un caso existente, usar Gestión de Casos.
  • Las fechas Desde/Hasta del filtro deben estar dentro de un mismo mes natural.
  • Un caso cerrado ya no se modifica ni se anula.
